# Resonance

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:8015。

## 场景入场方式

每个场景保存独立的入场（entrance）配置，替代旧的全局淡化：

- `fade` 淡化（交叉淡入淡出）
- `wipe` 方向擦除（左 / 右 / 顶 / 底）
- `reveal` 几何揭幕（圆形 / 方形 / 菱形，自中心展开）
- `expand` 跟随低频扩张（圆域随低频能量推进，约定结束时刻必然完整进入）

时长支持两种单位：

- 秒（seconds）：固定墙钟时长
- 拍（beats）：触发时按当前 BPM 结算为秒，写入本次转场契约

### 契约与进度归属

- 正式切场在**触发时刻**冻结本次转场契约（入场参数深拷贝快照 + 结算秒数）。
  演出中敲击改速只影响下一次触发，不能把当前转场拉回起点。
- 进度所有权归可重复的时间线：低频能量只做有界、单调的叠加（只增不减），
  持续静音时时间线仍按时把画面送到 100%，不会卡在半幅画面。
- 编辑场景入场方式时使用草稿 + 预演叠层，不改变正在演出的版本与 `activeId`；
  保存后从下一次正式切场生效。
- 遮罩全部绘制在 1280×720 backing 像素上（canvas clip），
  录制流（captureStream）与全屏预览共用同一画布，遮罩边缘完全一致。
- 边界：零时长当帧硬切；连续切换以当前合成帧为新基底并生成单调递增契约 id；
  暂停/挂起恢复后按绝对时间戳跳到对应进度，不重放。
